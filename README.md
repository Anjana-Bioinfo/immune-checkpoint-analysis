# Immune Checkpoint Expression Analysis

This project analyzes immune checkpoint gene expression in tumor and normal samples using R.

## Skills Used
- R programming
- Data visualization
- ggplot2
- Statistical testing

## Genes Analyzed
- PDCD1
- CTLA4
- CD274
- LAG3
- TIGIT

## Analysis Performed
- Data import
- Filtering
- Boxplots
- Heatmaps
- t-test analysis
